## Show Your Work — Portfolio That Proves Skill

Employers and clients do not care what you watched. They care what you **shipped**.

### Your portfolio must include

1. **Live links** — not localhost, not Figma-only
2. **GitHub repos** — clean README with setup steps
3. **Screenshots** — desktop + mobile
4. **What you built** — one paragraph: stack, features, your role
5. **What broke and how you fixed it** — shows real experience

### Where to put it

- Personal site (`yourname.com` — Chapter 13)
- GitHub profile pinned repos
- LinkedIn featured section
- Twitter/X thread when you ship
- WhatsApp status when you deploy (seriously — your network is your first client base)

### Portfolio Cursor prompt

```
Create a Projects section for my portfolio with 3 project cards: image, title, description, tech stack tags, Live Demo and GitHub links. Tailwind. Match my existing site style.
```

### What to remove

- Tutorial clones with zero changes
- Projects that do not run
- "Coming soon" with nothing live for months

**One live mediocre project beats five unfinished perfect ones.**

## Earn From It — Freelance & Products

Learning is phase one. **Income is phase two.** I learned to code while leading 40,000 students — not because I had free time, but because I needed skills that could change my income.

You can earn with the same stack this book teaches.

### Freelance services you can sell now

| Service | What client gets | Price range (NGN)* |
|---------|------------------|---------------------|
| Landing page | 1-page marketing site, mobile-ready, deployed | ₦50k–₦200k |
| Business website | 4–5 pages, contact form, deployed | ₦150k–₦400k |
| Online store MVP | Products, cart, checkout (test/live payments) | ₦300k–₦800k+ |
| Admin dashboard add-on | Manage products/orders | ₦100k–₦250k |
| Site redesign | Modern UI on existing content | ₦80k–₦200k |

*Ranges vary by city, client, and your confidence. Start lower to get testimonials. Raise prices after three paid projects.

### How to get first clients

1. **Your network** — church, campus, WhatsApp groups, friends with businesses
2. **Ship your own site** — proof you can do it for them
3. **Free or discounted first project** — only if they give written testimonial + referral
4. **Social proof** — post build-in-public screenshots and live links
5. **Local businesses without websites** — walk in with your phone showing a demo

### Freelance rules

- **50% deposit before you start** — non-negotiable after first client
- **Scope in writing** — "Landing page, 5 sections, contact form, deploy. Revisions: 2 rounds."
- **Do not undercharge forever** — your time has value
- **Use contracts** — even a simple WhatsApp agreement saved as PDF
- **Be honest about AI** — you use Cursor; you still deliver working product

### Product path (passive income)

Instead of client work only:

- Sell templates (landing page starters)
- Sell digital products on your own store
- Build a tool for your niche (schools, churches, creators)
- Write paid guides or courses

Royal Prince Hub started as projects that became platforms. Your store can sell **your** ebook, course, or templates.

## Keep Learning — After This Book

You do not need ten more courses before your next build. You need **one project** and curiosity.

### Learn by building

| Topic | When you need it | How to learn |
|-------|------------------|--------------|
| TypeScript | Larger codebases | Add to one new Vite project |
| Testing | Client asks for reliability | Jest + one component test |
| Redis/caching | Slow API at scale | Later — not day one |
| Python/Django | Different job requires it | After MERN is solid |
| Mobile (React Native) | Client wants app | After React is comfortable |

Remember Chapter 1: **MERN is one proven path, not the only path.** Master this path first.

### Daily habits that compound

- **Build 30–60 minutes daily** — even when tired (Chapter 7)
- **One Git commit minimum** on active project days
- **Read one error fully** before asking AI (Chapter 11)
- **Follow one builder** you admire — not for copying, for standards
- **Uninstall one distraction** when focus drops (I uninstalled Twitter to write *Leading from Within*)

## Debug Survival — Quick Reference

When you forget everything else, remember Chapter 11:

1. Read the full error
2. DevTools Console + Network
3. Is backend running? Is `.env` loaded?
4. Paste error + context into Cursor
5. One fix at a time
6. Log in `BUILD_LOG.md`

Pin Chapter 11. You will use it more than any syntax cheat sheet.
