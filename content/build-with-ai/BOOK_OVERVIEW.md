# Build with AI: From Zero to Full-Stack Developer

**Working Title:** *Build with AI: From Zero to Full-Stack Developer with Cursor*

## Book Overview

This book is a practical training guide for beginners who want to learn how to build real websites and web applications — not by memorizing syntax for years, but by understanding how the web works and leveraging **AI (Cursor)** as a development partner.

The author teaches from lived experience: the same stack used to build **Royal Prince Hub** — a portfolio site, digital bookstore, admin dashboard, and collaboration tools.

## Target Audience

- Complete beginners curious about web development
- Creators, entrepreneurs, and students who want to build their own sites
- People who have heard of HTML, React, or "full-stack" but don't know where to start
- Anyone who wants to use **Cursor AI** to move faster without skipping fundamentals

## Tone & Style

- Clear, encouraging, authoritative yet relatable (same voice as *Leading from Within*)
- Explain technical concepts in plain language before introducing jargon
- Use real-world analogies (restaurant, building a house, etc.)
- End each chapter with **Action Points**
- Include blockquotes where they reinforce a principle

## Chapter Outline (Full Book)

1. **The New Way to Build** — What web development is, frontend vs backend vs full-stack, MERN as the author's path (not the only path), core technologies, and how AI has changed the game
2. **Your Toolkit & The MERN Stack** — Every tool you need; GitHub, Vercel, Render, Cloudflare roles; AUTH, payments; AI assistants overview (ChatGPT, Gemini, DeepSeek)
3. **Leveraging AI — Your Co-Pilot** — Prompt engineering, languages AI understands, AI's role along the journey, developing UI/code judgment, daily AI workflow
4. **Website Elements — Text, Icons, Fonts & Color** — Typography, icons, font pairing, colour theory, and visual building blocks before you build
5. **Anatomy of a Website — Royal Prince Hub + Live Previews** — Navbar, hero, product cards, forms, footer; embedded UI demos in the book reader
6. **DIY — Do It Yourself (Copy, Paste, Build)** — Three tracks with staged Cursor prompts: single landing page, multi-page site, full e-commerce (phased)
7. **Think Wild — Build, Build, Build** — Mindset, no excuses, projects over reading; keep building like the author did
8. **Vibe Coding With Eyes Open** — `.env` secrets, auth deep-dive, catching AI architecture mistakes
9. **Deploying to the World** — Run locally, Git/GitHub push, Vercel + Render, MongoDB Atlas, Cloudinary, Flutterwave
10. **Backend Anatomy — Routes, Models & Data Flow** — Mongoose schemas, CRUD, controllers, middleware, frontend ↔ API data flow
11. **When Things Break — Debug Like a Builder** — Terminal, browser, auth, payment, and production error playbooks
12. **Admin Dashboard — Manage What You Built** — Protected admin routes, CRUD, layout, Royal Prince Hub admin pattern
13. **Custom Domain & Cloudflare — Look Professional Online** — DNS, SSL, domain + OAuth + CORS updates for production
14. **Your Next Build — Portfolio, Freelance & Keep Building** — Project ladder, show your work, earn in Naira, finale

## Reference Project

All tools and patterns in this book map to the **Royal Prince Hub** codebase:
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express + MongoDB (Mongoose)
- Auth: Google OAuth + JWT
- Payments: Flutterwave
- Hosting: GitHub + Vercel (frontend) + Render (backend) + Cloudflare (DNS/security)
