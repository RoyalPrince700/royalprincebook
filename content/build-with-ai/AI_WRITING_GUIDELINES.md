# AI Writing Guidelines — Build with AI

**Book Title:** *Build with AI: From Zero to Full-Stack Developer with Cursor*

## Book Overview

Practical web development training for beginners who want to build real websites and applications using the **MERN stack** and **Cursor AI**. The author teaches from the same stack used to build Royal Prince Hub.

## Target Audience

- Complete beginners (no prior coding required)
- Creators, entrepreneurs, and students
- Followers who want to leverage AI to build faster
- International audience — explain local context (Naira, Flutterwave) when relevant

## Tone & Voice

Match the author's voice from *Leading from Within*:
- Inspiring, authoritative yet relatable
- Direct address ("you", "I")
- Real-world analogies (restaurant, LEGO blocks, filing cabinet)
- Personal conviction without arrogance
- Action Points at the end of every chapter

## Technical Standards

- Explain concepts in plain English before jargon
- Include download links for every tool
- Use tables and diagrams for architecture
- Code snippets should be minimal and illustrative
- Map every tool to the Royal Prince Hub project where possible
- Security reminders: `.env`, never commit secrets, verify payments server-side

## Chapter Structure

Each chapter follows this pattern:
1. Opening blockquote
2. Hook — why this chapter matters
3. Core content with `##` and `###` headings
4. Real examples from the author's project
5. Conclusion
6. Action Points (numbered list)

## Content Location

- Authoring drafts: `content/build-with-ai/chapter*.md`
- Glossary: `content/build-with-ai/GLOSSARY.md`
- App integration: `frontend/src/chapters/build-with-ai/`
- Reference project: root monorepo (`frontend/` + `backend/`)
